# Third-party software and intellectual property

MacroLoom integrates at runtime with external addons and game APIs. This archive does not bundle them.

- **SuperCleveRoidMacros / CleveRoidMacros:** external macro parser, resolver, and execution APIs.
- **SuperMacro:** external macro editor and Extended Lua support.
- **pfUI:** optional external action-bar, tooltip, and macro-editor integration.
- **World of Warcraft / Turtle / Octo game environments:** external clients, names, spells, and APIs. Trademarks and game assets belong to their respective owners.

Those components are **not covered by MacroLoom's MIT license** and must be obtained under their own applicable terms. MacroLoom's code refers to game spell names and pre-existing API identifiers but does not distribute client assets.

No third-party source files or packaged art assets were identified in the supplied addon-only ZIP. A file inspection cannot establish the historical origin of every code fragment; contributors should confirm ownership and any upstream attribution obligations before public publication.
